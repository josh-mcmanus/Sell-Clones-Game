# Incremental Cloning Game

An unfinished 2D incremental game developed in Godot using C#.
The game centers around upgrading and modifying clones, by managing their body parts.



## Overview

The idea behind this project was to build an incremental game where clones could be modified by adding and removing different body parts. All upgrades revolved around a node based system, where the player can purchase new nodes to increase the rate that upgrade 'points' accumulate, which are then traded in for new body parts to attach to the clone template.



## Gameplay

You start out with a base 'clone template' which you progressively upgrade by slotting in higher tier body parts.


New body parts are unlocked automatically by research points, which are produced by research nodes.
An increasing amount of points are required to unlock higher tier body parts.


All sections, research nodes and clone tanks, more can be purchased to increase the rate that money and reasearch points are aquired.


Everything can be upgraded, including the research nodes and cloning tanks. 
There are various upgrade slots for the reasearch node and cloning tank templates. These can be upgraded in a similar slot in system as the clone template. (This is not fully implemented).



## Project Status

Development was discontinued before the game was finished. The repository is being made public to document the work completed and demonstrate my programming experience through a personal game development project.

The game is unfinished, but the source code provides an example of my work with C#, gameplay systems, and structuring a project in Godot.
